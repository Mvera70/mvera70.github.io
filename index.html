Proyecto personal en pruebas

Fallo and Respawn Clipping

Una herramienta personal de Miguel Vera para preparar cortes de vídeo, revisar sus subtítulos y decidir qué hacer con cada pieza.

La grabación y el análisis se realizan en equipos propios. Las conexiones con plataformas se utilizan únicamente para las salidas autorizadas.

Cómo se usan los datosCondiciones de uso

Un panel de uso personal

Esta web explica la aplicación. No ofrece registro público ni acceso a la biblioteca, a las grabaciones o al servidor privado.

Conexión opcional con YouTube

La aplicación utiliza los Servicios de API de YouTube para identificar el canal autorizado, subir el vídeo elegido y comprobar el resultado. El piloto está configurado para pruebas privadas.
