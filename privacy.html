Política de Privacidad

Versión del 17 de noviembre de 2026

Esta política describe el uso de datos de Fallo and Respawn Clipping, una herramienta personal de Miguel Vera. La web informativa y el panel privado tienen funciones distintas.

Quién gestiona la aplicación

Responsable: Miguel Vera, proyecto Fallo and Respawn Clipping. Para preguntas, solicitudes de eliminación o consultas de privacidad, escribe a falloyrespawn@gmail.com.

Qué datos se utilizan

Archivos de trabajo
Vídeos, fragmentos, transcripciones, subtítulos y decisiones de revisión que se incorporan al proyecto. Se conservan en equipos propios con acceso restringido.
Conexión con Google
Credenciales de autorización y renovación, permisos concedidos e identificador del canal autorizado. No se solicita ni se guarda la contraseña de Google.
Datos de YouTube
Identificador del canal y, para las subidas seleccionadas, identificador del vídeo y datos necesarios para comprobar canal, privacidad y estado de la operación. La aplicación utiliza los Servicios de API de YouTube.
Recibos de operación
Datos técnicos para evitar subidas repetidas y comprobar resultados. Las credenciales y los enlaces de transferencia se mantienen fuera de esta web pública.

Para qué se usan

Los archivos se emplean para preparar y revisar cortes. Los datos de Google se emplean para conectar el canal elegido, ejecutar las subidas expresamente autorizadas y comprobar su resultado.

No se venden datos personales ni se utilizan los datos obtenidos de Google para publicidad o entrenamiento de modelos de inteligencia artificial. El uso de datos recibidos de las APIs de Google se limita a las funciones autorizadas y está sujeto a la Política de Datos de Usuario de las APIs de Google, incluidos sus requisitos de uso limitado.

Qué servicios pueden recibir datos

YouTube recibe el archivo y sus datos cuando se autoriza una subida a ese destino. Su tratamiento se rige también por la Política de Privacidad de Google y las Condiciones del Servicio de YouTube.

Una transferencia autorizada a Metricool puede utilizar un almacén privado de Supabase y un enlace temporal para entregar el vídeo. Metricool importa una copia del archivo. La caducidad del enlace de origen no borra el archivo de Supabase ni la copia de Metricool; el enlace de la copia puede permitir la descarga a quien lo obtenga. Esta transferencia requiere autorización específica y no se deriva de aprobar el montaje.

No se envían automáticamente archivos ni datos obtenidos de Google a servicios de IA externos. Otros servicios solo se conectan con autorización del propietario y para la finalidad indicada.

Conservación y eliminación

Los archivos de edición permanecen en los equipos propios hasta que su propietario decide eliminarlos. No hay una limpieza automática de los originales. Las copias de transferencia y los borradores de los proveedores requieren una eliminación independiente; no desaparecen por caducar un enlace.

Los datos obtenidos de YouTube se conservan solo mientras sean necesarios para la conexión y las operaciones autorizadas. Deben actualizarse o eliminarse según los plazos de las políticas de YouTube. Una solicitud de eliminación de esos datos se atiende lo antes posible y dentro de siete días naturales; tras una revocación realizada en Google, la eliminación debe completarse dentro de treinta días naturales. Este procedimiento se gestiona por el contacto del proyecto.

Para solicitar la eliminación, escribe a falloyrespawn@gmail.com e indica qué conexión o datos quieres retirar. No envíes contraseñas ni códigos de acceso. La eliminación de datos de la aplicación no elimina por sí sola los vídeos alojados en YouTube o en otras plataformas.

Cómo retirar el acceso a Google

Puedes revocar la conexión desde la configuración de permisos de tu cuenta de Google. La revocación impide nuevas operaciones autorizadas mediante esa conexión; no borra automáticamente los vídeos que ya estén en YouTube.

También puedes contactar con el responsable para retirar la conexión y solicitar la eliminación de sus datos locales. La retirada del acceso y la eliminación de datos son acciones distintas.

Esta web informativa

No incorpora publicidad, formularios de registro, analítica ni rastreadores de terceros. Guarda únicamente la preferencia de tema claro u oscuro en el almacenamiento local del navegador; puedes borrarla desde tu navegador.

Si estas páginas se publican en GitHub Pages, el proveedor de alojamiento puede registrar direcciones IP y peticiones para prestar y proteger su servicio. Consulta la declaración de privacidad de GitHub.

Cambios de funcionamiento

Esta política se actualizará antes de introducir usos de datos que no cubra. Una ampliación del acceso o de la finalidad requiere informar y obtener la autorización correspondiente.
